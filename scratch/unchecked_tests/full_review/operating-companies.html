Operating Companies

Oct. 17, 2023

Operating companies are required to submit their financial statement and certain other information in Inline eXtensible Business Reporting Language (XBRL). Learn more about Inline XBRL. The SEC staff strongly encourages companies to use the most recent version of the relevant taxonomy for their XBRL submissions to take advantage of the most up to date tags related to new accounting and disclosure standards and other improvements.

Attachment Type EX-101.*

The table for each taxonomy release provides a list of taxonomy files to which the XBRL submissions may refer. None of the taxonomy files listed may be included with a submission that contains the XBRL instance. XBRL submissions may not refer to any external taxonomy files other than these taxonomy files.

For details of unit type registry versions for operating company Inline XBRL submissions, see EDGAR XBRL Guide section 2 - XBRL Specifications.

Each taxonomy release has a “family name" and "version." Each taxonomy has a complete Zip format archive containing all its files, whether those files are accepted by EDGAR or not. Locations of the actual schema and linkbase files to be used are given so that you may download these taxonomies for use in validating your instance document prior to a live submission to the Commission. Technical users can find the XML version of the taxonomy files with relevant family, version, and website.
